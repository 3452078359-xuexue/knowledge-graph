## 结构化表格导出

空间行政区数据同时提供机器可导入的全量 CSV 与可审阅的多工作表 XLSX。字段名称与顺序按 `CityTourism.schema` 导出，多值字段保留为 JSON 数组；官方行政区来源层与 H3/地名索引派生层分开审核。

| 表格 | 内容 | 记录数 |
|---|---|---:|
| `贵阳市空间行政区数据_结构化总表.xlsx` | 摘要、实体、关系汇总样本、官方审核、字段字典 | 53,446 个实体 / 178,426 条关系口径 |
| `贵阳市城市结构化表.csv` | `City` 全量 | 1 |
| `贵阳市行政区结构化表.csv` | `AdminArea` 全量 | 157 |
| `贵阳市商圈片区结构化表.csv` | `Zone` 全量 | 171 |
| `贵阳市H3空间网格结构化表.csv` | `GeoCell` 全量 | 13,011 |
| `贵阳市地名别名索引结构化表.csv` | `PlaceAlias` 全量 | 40,106 |
| `贵阳市空间行政区关系明细表.csv` | 5 类空间实体发出的全部关系 | 178,426 |
| `贵阳市官方行政区审核表.csv` | 官方行政区来源与核验状态 | 157 |

XLSX 为审阅总表：城市、行政区、商圈和官方审核保留全量；H3 网格按分辨率保留 3,714 条分层样本，地名别名按目标实体类型保留 3,247 条分层样本，关系按类型保留 1,556 条样本。批量导入必须使用同目录全量 CSV。

空间检索口径：先由 `PlaceAlias.targetCell/targetCellR9` 一跳定位，再按半径扩展 H3 邻格并计算精确距离；`adminAmbiguous=是` 的格子不能直接用于行政区统计，需回到 POI 的行政区关系逐条计算。
