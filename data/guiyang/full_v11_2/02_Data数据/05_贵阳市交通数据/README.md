## 结构化表格导出

交通数据同时提供机器可导入 CSV 与多工作表 XLSX。字段名、顺序、类型及约束均与 `CityTourism.schema` 对齐；多值字段以 JSON 数组保存，图谱关系单独展开。

| 表格 | 内容 | 记录数 |
|---|---|---:|
| `贵阳市交通数据_结构化总表.xlsx` | 摘要、6 类实体、关系明细、字段字典 | 9,604 个实体 / 53,457 条关系 |
| `贵阳市交通枢纽结构化表.csv` | `TransitHub` | 4 |
| `贵阳市公交线路结构化表.csv` | `TransitLine` | 302 |
| `贵阳市交通路线结构化表.csv` | `TransitRoute` | 372 |
| `贵阳市公交站点结构化表.csv` | `TransitStop` | 3,630 |
| `贵阳市交通设施结构化表.csv` | `TransitFacility` | 5,279 |
| `贵阳市交通票价规则结构化表.csv` | `TransportFareRule` | 17 |

空间口径：公交站点既可能自带精确坐标和 H3，也可能通过 `spatialFacility` 连接地图 POI。不得因为语义站点自身 H3 为空就判定为无法定位。
