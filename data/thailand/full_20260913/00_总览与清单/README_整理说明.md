# 泰国数据业务分类整理包

整理日期：2026-09-13

本交付包是在全新的目录中对本地泰国数据进行复制、分类和索引。原始目录中的文件没有被移动、重命名、覆盖或改写。

## 文件夹命名

一级目录采用 `分类号_业务类型`，来源目录采用 `分类号_业务类型-数据来源`。例如：

- `03_美食餐饮/03_美食餐饮-GoogleMapsPlaces`
- `04_交通出行/04_交通出行-Transitland_NAMTANG_GTFS`
- `05_酒店住宿/05_酒店住宿-携程`

## 数据处理边界

- 原样复制文件均已比对源文件与交付副本 SHA256，结果一致。
- 小红书当前唯一正式版在 `01_旅游综合` 中完整原样保留。
- 其他业务目录中的小红书 CSV 是新增衍生副本，只按 `POI业务类型` 精确筛选；没有修改列结构或单元格值，也没有跨来源去重。
- 不把不同地域范围强行混合。小红书以泰国全域为主；Google Places、携程与酒店多平台数据主要为曼谷；Transitland/NAMTANG 与行政区数据为全国范围。
- 票价、房价、营业时间、交通时刻与平台状态均是对应采集日期的快照，不代表打开文件时的实时状态。

## 使用顺序

1. 先看 `01_分类与来源总览.md` 和 `02_数据洞察与质量边界.md`。
2. 用 `05_数据文件清单.json` 查原始路径、处理方式、行列数和校验值。
3. 按业务下载 `分业务ZIP` 中的独立压缩包；需要全部数据时使用目录外的全量 ZIP。
