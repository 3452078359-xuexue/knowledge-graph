# 曼谷携程景点采集

本次以「曼谷地区景点批量采集」为交付目标，参考荔波酒店程序的列表发现、ID 去重、
详情补采、逐条原子保存、断点续跑和验证即停设计，改写为独立的公开景点页面采集器。
不依赖原酒店程序的位置，不修改荔波数据，也不混入 Google Places 的评分。

## 入口与两种 ID

- 景点列表：<https://you.ctrip.com/sight/bangkok191.html>，景点目的地 `districtId=191`。
- 酒店列表：<https://hotels.ctrip.com/hotel/Bangkok359/>，酒店城市 `cityId=359`。
- 景点 `poiId` 与详情路径里的 `businessId` 不总相同。例如大皇宫分别为 `77012`、`7290`。
  去重使用 `poiId`，详情 URL 使用原卡片提供的链接，并再次核验详情主体 ID。
- 详情 `/0.html?poiId=...` 通常是特色体验合集。查询参数是必需信息，不能直接删除后请求；
  本程序保留发现条目、标记跳过详情，不触碰 robots 禁止的带参数 URL。

## 运行

需要 Python 3.10+ 和 `curl`（本机已验证），核心不需要安装第三方 Python 包。
以下命令在本项目根目录执行。输出 JSON 是可持续复用的数据与断点；Excel/CSV 为另行导出的阅读版本。

```bash
# 离线参数检查：不联网、不创建输出目录
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' --dry-run

# 先验证两页列表和三个详情；测试结果与正式结果隔离
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' \
  --output '03_携程曼谷景点/00_测试结果/在线小样' --max-pages 2 --max-details 3

# 首批 10 页 + 其中的本地常设景点/体验详情，默认每 4 秒至多启动一个请求
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' --max-pages 10

# 同一输出目录续采至累计 20 页；不会重新请求已保存的列表页或成功详情
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' --max-pages 20

# 只发现列表 / 只补详情 / 只补缺失字段 / 从断点重新导出 JSON
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' --mode discover --max-pages 10
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' --mode details
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' --mode backfill
python3 '03_携程曼谷景点/99_采集程序/携程_曼谷景点批量采集.py' --mode export

# 运行离线回归测试
python3 -m unittest discover -s tests -p 'test_ctrip_sights.py' -v

# 正式采集结束后，核验实际来源字段与导出、要求本地详情全部成功
python3 '03_携程曼谷景点/99_采集程序/核验_曼谷景点结果.py' --require-main-details
```

也可双击本目录的 `.command` 文件。`--max-pages` 是**同一断点目录的累计页数上限**，
`--max-details` 是本次详情尝试次数上限（0 表示符合条件的全部）。
`--details-scope all` 可为已发现的周边条目补详情，但不会将它们合并为曼谷本地景点。

如迁移到泰国其他城市，先核实官方景点页面的 slug 和目的地 ID，再同时设置
`--city-name`、`--district-id`、`--slug`，并使用**新的** `--output` 目录。
程序拒绝用另一个城市的配置覆盖已有断点。

## 字段与数据口径

- 名称：中文、英文、页面本地名；仅确实包含泰文字母时才写入泰文名，不自动翻译或猜测。
- 评分：`rating` 为 5 分制；`heat_score` 是独立热度，绝不作为评分。真实无评分留空。
- 点评：从 `listInitData.attractionList[].card.commentCount` 或
  `poiDetail.commentCount` 获取完整数字；不使用页面「1.3万」缩写，
  也不误用 `commentTotalCount`（当前点评子集）。保留列表值和详情值以便核对。
- 空间：目的地、区域/商圈、地址、经纬度、原坐标系与坐标来源。
  曼谷本地主要依据 `districtId=191`，非行政边界测绘结果；外府地址冲突列为待核验。
- 分类：景点/场所、演艺/游船/体验产品、限时活动、特色体验合集。
  主表只含本地且非限时活动/合集的条目；常设演艺/游船产品明确标出类别。
- 营业：原始营业时间、按结构化规则整理的营业时间、特殊日期提示、建议游玩时长、联系电话。
- 价格：列表展示起价、划线价、免费标记、符号、平台提供的币种代码（如有）、采集时间和来源。
  `price=0` 不是免费，只有明确 `isFree=true` 才写免费。页面未给 ISO 币种时保留空值与 `¥` 符号，
  不擅自标成泰铢，也不进行汇率换算。此价格不是指定出游日期的最终结算价。
- 来源：保留真实列表 URL、详情 URL、评分/点评/坐标的各自来源和采集时间。
- 图片仅保留公开图片链接；不下载图片，不采点评正文、评论用户信息、长篇景点介绍或登录数据。

## 输出与续跑

默认输出目录：`01_采集结果/曼谷景点_首批`。

- `checkpoint.json`：规范化记录、精选来源字段、分页断点、运行和失败事件；每页/每个详情原子保存。
- `曼谷景点_全部发现.json`：全部去重条目，包括周边和不同类型，用于完整审计。
- `曼谷景点_本地景点.json`：本地常设景点与体验主表。
- `曼谷景点_价格快照.json`：与景点稳定字段分开的带时间价格快照。
- `质量报告.json`：数量、字段覆盖率、未补详情、异常、下一页链接及非全量声明。

Excel 和 UTF-8 BOM CSV 导出位于项目 `outputs/ctrip_bangkok_01a05592/`，中文列名便于阅读。
这些表格是导出时的快照；后续采集更新 JSON 后需重新导出表格，不能把旧表格当最新结果。

程序只跟随页面实际提供的下一页链接。不同页返回相同景点集合会停止，不能把重复页面算作新增。
列表中的 `totalCount=3000`、`totalCountDesc=1万+` 是平台不同显示口径，
不代表本次获取了 3000 条，更不表示已覆盖全部曼谷景点。

退出码：0＝本次配置批次完成（不代表城市全量）；2＝解析/网络等导致部分完成；
3＝平台验证、403/429 或 robots 禁止；130＝人工中断。详情失败事件与状态会写入质量报告。

## 安全边界

每次在线运行先读取官方 robots.txt，支持其通配规则、最长 Allow/Disallow 与 Crawl-delay。
只访问公开 HTTPS 景点 HTML；不调用私有接口、不传登录 Cookie、不使用代理轮换、签名伪造或验证码规避。
403/429/登录/验证立即停止，不自动重试；一般网络错误有限重试。输出目录有互斥锁，防止两进程覆盖断点。
请仅在有权使用相关数据的范围内运行，避免将公开采集误当作平台的数据转售授权。
