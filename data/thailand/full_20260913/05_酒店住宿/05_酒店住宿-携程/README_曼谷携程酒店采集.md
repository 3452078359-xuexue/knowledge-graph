## 采集程序与续采

日常使用项目根目录的 [携程-泰国-曼谷.py]([LOCAL_HOME]/Desktop/Thailand---泰国/携程-泰国-曼谷.py)。

在 PyCharm 中直接点“运行”且不填写任何脚本参数时，程序会自动选择现有酒店 ID
数量最多的曼谷清单。目前会自动读取 `2026-09-28` 至 `2026-09-29` 的 869 家
清单，进入详情续采、跳过已保存记录，并在房型/价格接口受限时继续保存其他详情。
不会再按当天日期新建空目录，也不会重新执行“更多曼谷酒店查询”。
详情采集会复用专用 Chrome 中一个固定的“酒店监看标签”，并在后台把该标签
更新为当前酒店 URL；不会强制切换当前标签或抢占屏幕。需要查看时手动点击该
携程标签，即可看到当前/最新酒店页面，同时仍可在其他应用或浏览器页面工作。
酒店之间的随机等待已关闭，完成一家后直接处理下一家；页面加载等待仍会保留。

先做离线检查（不打开浏览器、不联网、不改数据）：

```bash
python3 -B "[LOCAL_HOME]/Desktop/Thailand---泰国/携程-泰国-曼谷.py" --dry-run --checkin 2026-09-28 --checkout 2026-09-29
```

只有需要重新发现列表时才显式使用 `collect` 模式：

```bash
python3 "[LOCAL_HOME]/Desktop/Thailand---泰国/携程-泰国-曼谷.py" --mode collect --checkin 2026-09-28 --checkout 2026-09-29
```

如只处理已有清单中的酒店详情，本次最多新处理 20 家：

```bash
python3 "[LOCAL_HOME]/Desktop/Thailand---泰国/携程-泰国-曼谷.py" --mode details --max-new-hotels 20 --checkin 2026-09-28 --checkout 2026-09-29
```

如果房型、房价或售卖方案接口返回 `203`，先继续保存其他有效详情：

```bash
python3 "[LOCAL_HOME]/Desktop/Thailand---泰国/携程-泰国-曼谷.py" --mode details --continue-without-sales --checkin 2026-09-28 --checkout 2026-09-29
```

该模式只处理已有清单，不重新发现列表。受 `203` 影响的房型、售卖方案和相关图片会丢弃并登记在“酒店_房型待补（风控）表”，其余实际成功读取的基础信息、设施、政策、酒店图片和周边地点照常保存。页面登录、验证码或人工验证仍会停止，不绕过平台限制。

- `--mode discover`：只发现列表；已有酒店 ID 会合并保留，不表示直接从上次页面位置继续。
- `--mode login`：打开专用浏览器供人工登录。
- 当次遇到登录或平台验证仍暂停，保留已保存的数据，不绕过验证。
- 两个历史酒店 `.command` 启动脚本仍保留，使用旧入口和旧输出规则；续采当前 869 家清单请使用上面的主入口命令。
