# 公开数据与治理策略

## 目的

本仓库用于公开知识图谱的设计、Schema、可复现空间框架和具备明确来源的数据快照，不是采集运行目录，也不是第三方平台数据镜像。

## 可以进入公开仓库

- 自研 Schema、字段说明、查询和证据治理设计；
- 官方或开放许可行政区数据，并保留来源、日期和许可说明；
- 自行派生的 H3 空间骨架及聚合统计；
- 不包含用户正文的质量报告和数据清单；
- 仅为解释结构而制作的无个人信息样例。

## 不进入公开仓库

- API Key、Cookie、浏览器 Profile、登录状态、代理配置和采集日志；
- 高德、Google Maps / Places、携程、Trip.com 的原始 API 响应或未确认可再分发的全量数据；
- 小红书帖子全文、评论正文、作者名称、头像和带临时访问参数的 URL；
- 动态房价、票价、营业状态等可能过期并受平台条款限制的快照；
- 本地数据库、缓存、失败截图和人工审核中的未脱敏材料。

## 图谱分层

```text
事实主实体（POI）
    ↑ EVIDENCE_FOR
SourceEvidence（审核后的短证据）
    ↓ EXCERPT_OF
SocialPost / SourceDocument（本地受控内容库）
```

公开层默认只保留来源 ID、稳定 URL、短引文、时间和审核状态。全文保存在本地受控内容库中，并由回答 Agent 按权限通过 ID 获取。

## 数据不等于授权

文件存在于本地或能够通过公开网页/API 获取，不代表可以将原始内容再次公开发布。使用者需要根据来源条款、许可、署名要求和目标使用场景自行判断可发布范围。

本仓库没有为所有文件提供统一的数据许可证。代码、Schema、官方行政数据和第三方来源材料的权利边界不同；使用前应阅读相应目录中的来源说明。

## 提交前检查

1. 搜索密钥、令牌、Cookie、Session 和本机绝对路径；
2. 检查是否包含评论、帖子正文或作者信息；
3. 检查单文件是否超过 GitHub 100MB 限制；
4. 对 JSON 执行语法检查，对 CSV 核对表头与记录数；
5. 更新公开快照清单和来源日期；
6. 推送前审阅 `git diff --cached`。
